大事なのは、GPU の速さより VRAM

VRAM は、GPU 専用のメモリです。足りないと、VRChat ではワールドやアバターが重くなり、AI ではモデルがそもそも動きません。

  1. VRAM でえらぶ

    GPU ごとの VRAM を見て、足りる GPU を予約します。

  2. ネット越しにつなぐ

    自分の機材から、借りた PC の GPU を使います。

  3. 終われば元どおり

    時間になると自動で終了。ログイン情報は消え、貸した PC も元に戻ります。

使っていない GPU を貸す

ゲーミングPCの空いている時間を貸し出せます。貸し出し中はキーボードとマウスを止め、終わったら自動で片づけます。
