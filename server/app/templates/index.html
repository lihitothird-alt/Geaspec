GPU をさがす GPU を貸す

1台で足りない VRAM は、数台で

AI やレンダリングでは、GPU の速さより VRAM の量が効きます。VRAM が足りないと、AI のモデルはそもそも動きません。大きな GPU を1台買う代わりに、そこそこの GPU を必要な台数だけ借ります。

  1. VRAM でえらぶ

    GPU ごとの VRAM を見て、必要な量になるまで選びます。

  2. 数台まとめて借りる

    同じ時間に、数台をまとめて予約します。

  3. 終われば元どおり

    時間になると自動で終了。データは消え、貸した PC も元に戻ります。

まとめ借りは準備中です。使いたい方は、geaspec.contact@gmail.com に「やりたいこと」と「ほしい VRAM の量」を送ってください。始めるときにお知らせします。
