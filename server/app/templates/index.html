あなただけのAI 組織を。

何台もの GPU をひとつの組織のように動かして、AI やレンダリングを同時に回す。足りない VRAM は、台数で VRAM増強。Geaspec は、ゲーミングPCの GPU を個人どうしで貸し借りするサービスです。

GPU をさがす GPU を貸す

1台で足りないなら、何台でも

AI やレンダリングでは、GPU の速さより VRAM の量が効きます。VRAM が足りないと、AI のモデルはそもそも動きません。大きな GPU を1台買う代わりに、必要な台数の GPU を集めて、ひとつの組織のように動かします。

  1. VRAM でえらぶ

    GPU ごとの VRAM を見て、必要な量になるまで選びます。

  2. 何台もまとめて借りる

    同じ時間に、何台もの GPU をまとめて予約します。

  3. 終われば元どおり

    時間になると自動で終了。データは消え、貸した PC も元に戻ります。

複数台の貸し出しは準備中です。使いたい方は、geaspec.contact@gmail.com に「やりたいこと」と「ほしい VRAM の量」を送ってください。始めるときにお知らせします。
