From request to result

Guests never operate a host's PC, and no accounts are shared.

  1. Request

    The guest describes the work and the form of the result.

  2. Approval

    Requests that fit the host's conditions (hours, uses, time limit, specs) are approved automatically; others are up to the host.

  3. Run

    The host runs it on their own PC, with the models and tools they choose.

  4. Result

    Only the result comes back, after a checker has verified it.

VRAM on several PCs does not become one big memory. More PCs means more AIs running at once, each with its own context.
