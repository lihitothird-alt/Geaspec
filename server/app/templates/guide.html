はじめての方へ

テストに参加するときに使う画面を、画像で説明します。

1. Meta ユーザー名の見つけ方 2. 当日までの準備 3. 当日のつなぎ方 4. FPS と Ping の見方

1. Meta ユーザー名の見つけ方

Discord で申し込むときに使います。表示名ではなく、ユーザー名のほうです。Virtual Desktop を持っている人は、VD で使っているものと同じです。

  1. スマホで Meta Horizon アプリを開きます。

  2. 下に並んでいるボタンの、まん中の人の形のボタン（プロフィール）を押します。

  3. 名前の下にある、@ で始まる文字がユーザー名です。申し込みには @ のあとの部分を入れてください。

2. 当日までの準備

  • 当日は PC 版の VRChat に、自分のアカウントでログインします。VRChat のメールアドレス（またはユーザー名）とパスワードを用意してください。
  • 2段階認証をしている人は、確認コードを受け取るスマホも手元に置いてください。
  • 家の Wi-Fi で参加してください（スマホのテザリングだとつながらないことがあります）。
  • VPN は切ってください。Quest・スマホ・パソコン・家のルーターで VPN を使っていると、つながらないことがあります。
  • FPS と Ping の表示は、貸し出しの PC では毎回消えます。当日 VRChat に入ったら、下の手順でオンにしてください。
  • 自分の PC を貸す人だけ: 自分の PC の Virtual Desktop Streamer で「Allow remote connections」（外からの接続を許可）にチェックを入れてください。借りるだけの人は何もしなくて大丈夫です。

3. 当日のつなぎ方

  1. 開始 5分前に、Discord のスレッドで「テストを始める」を押します。
  2. Quest で Virtual Desktop を開き、パソコンの一覧から貸し出しの PC を選びます。
  3. VRChat が自動で立ち上がったら、自分のアカウントでログインします。
  4. 終わりの時間になると自動で終わり、ログイン情報はパソコンから消えます。

4. FPS と Ping の見方

  1. VRChat のメニュー（Launch Pad）の下にある歯車のボタン（設定）を押します。

  2. 設定をいちばん下までスクロールし、「デバッグ」の中の「FPS と Ping の表示」をオンにします。

  3. 画面に FPS と PING の数字が出ます。決められたワールドのスポーン地点で 30秒立ったまま、この数字を見てください。

数字は Discord の「数字を入れる」から入れるか、スクショをスレッドに貼ってください。
