PC を借りる人 PC を貸す人
{% if not lend %}

Quest から PC を借りてテストするときに使う画面を、画像で説明します。

参加の条件: Quest に Virtual Desktop（Meta のストアで買う有料のアプリ）が入っていること。持っていない人は、先に自分で買っておいてください。テストへの参加にはお金はかかりません。

1. Meta ユーザー名の見つけ方 2. 当日までの準備 3. 当日のつなぎ方 4. FPS と Ping の見方

1. Meta ユーザー名の見つけ方

Discord で申し込むときに使います。表示名ではなく、ユーザー名のほうです。Virtual Desktop を持っている人は、VD で使っているものと同じです。

  1. スマホで Meta Horizon アプリを開きます。

  2. 下に並んでいるボタンの、まん中の人の形のボタン（プロフィール）を押します。

  3. 名前の下にある、@ で始まる文字がユーザー名です。申し込みには @ のあとの部分を入れてください。

2. 当日までの準備

  • 当日は PC 版の VRChat に、自分のアカウントで、メールアドレス（またはユーザー名）とパスワードを使ってログインします。Steam や Meta でのログインは使えません（Steam でログインすると、貸してくれる人のアカウントになってしまいます）。
  • Quest でいつも Meta のボタンだけでログインしている人は、VRChat の公式サイトにメールアドレスとパスワードでログインできるか、先に確かめてください。
  • 2段階認証をしている人は確認コードを受け取るスマホを、そうでない人も VRChat から届く確認メールを見られるようにしておいてください（はじめての PC でログインすると、確認コードを聞かれることがあります）。
  • ルール: VRChat を開いたとき、もし自分ではない人のアカウントでログインされていたら、何も触らずに Discord の「困った」を押してください。テストはそこで中止します（貸してくれた人を守るためです）。
  • 家の Wi-Fi で参加してください（スマホのテザリングだとつながらないことがあります）。
  • VPN は切ってください。Quest・スマホ・パソコン・家のルーターで VPN を使っていると、つながらないことがあります。
  • FPS と Ping の表示は、貸し出しの PC では毎回消えます。当日 VRChat に入ったら、下の手順でオンにしてください。
  • 自分の PC を貸す人は、上のスイッチで「PC を貸す人」に切り替えると、貸すための手順が読めます。

3. 当日のつなぎ方

  1. 予約したら、Discord の自分のスレッドに戻って「予約した」を押します。テストのチェックリストが出るので、当日はそれに沿って進めます。
  2. 開始 5分前に、チェックリストの「テストを始める」を押します。
  3. Quest で Virtual Desktop を開き、パソコンの一覧から貸し出しの PC を選びます。
  4. VRChat が自動で立ち上がったら、メールアドレス（またはユーザー名）とパスワードで、自分のアカウントにログインします。Steam のボタンは押さないでください。
  5. 写真を貼って、アンケートに答えたら、チェックリストの「送信してテストを終える」を押します。これでテストは完了です。
  6. 早く遊び終わったら、Discord の「いま終わる」（または予約ページの「いま終わる」）を押すと、すぐに終わってログイン情報が消えます。
  7. 終わりの時間になると自動で終わり、ログイン情報はパソコンから消えます（自分でログアウトしなくて大丈夫です）。

4. FPS と Ping の見方

  1. VRChat のメニュー（Launch Pad）の下にある歯車のボタン（設定）を押します。

  2. 設定をいちばん下までスクロールし、「デバッグ」の中の「FPS と Ping の表示」をオンにします。

  3. 画面に FPS と PING の数字が出ます。決められたワールドで 30秒ほど歩き回りながら、この数字を見てください（だいたいの数字で大丈夫です）。

FPS と PING が写るように Quest のスクリーンショット（右手の Meta ボタンを押したまま、トリガーを引く）を撮って、Discord の自分のスレッドに貼ってください。テストが終わってから、スマホから貼っても大丈夫です。

準備ができたら、予約しましょう

予約する

開けないときは、Discord の自分のスレッドにある「サイトを開く」ボタンを押してください（あなた専用のリンクが届きます）。

自分の PC を貸してテストするときの手順です。借りるだけの人は、上のスイッチで「PC を借りる人」に切り替えてください。

1. Virtual Desktop Streamer の準備 2. Geaspec アプリを入れる 3. アカウントを作ってログイン 4. 貸せる時間を決める 5. 貸す日にすること・終わったら確かめること

1. Virtual Desktop Streamer の準備

  1. Virtual Desktop Streamer（無料・「Download Streamer」ボタン）を入れて開きます。
  2. 「Allow remote connections」（外からの接続を許可）にチェックを入れます。借りる人は家の外からつなぐので、これがないとつながりません。
  3. 予約が入ると、借りる人の Meta ユーザー名を運営から伝えます。Streamer のユーザー名の欄に追加してください（いまは手で入れてもらっています）。

2. Geaspec アプリを入れる

貸し出しのたびに、その Windows ユーザーの VRChat のログイン情報と設定を消します。ふだんの VRChat の設定を残したい人は、貸し出し専用の Windows ユーザーを作って、そこで入れてください。

  1. Discord のスレッドに届いたリンクから、Geaspec アプリ（GeaspecAgent-Setup-….exe）をダウンロードして開きます。

  2. 青い画面「Windows によって PC が保護されました」が出たら、「詳細情報」を押します。まだ署名（お金がかかる証明書）をしていないために出る画面で、中身は公開しているプログラムです。

  3. 下に「実行」のボタンが出るので、押します。

  4. セットアップの画面で「インストール」を押します。終わると Geaspec アプリが開きます。

3. アカウントを作ってログイン

  1. Discord のスレッドに届いた、あなた専用のリンクから予約サイトを開き、メールアドレスとパスワードを決めてアカウントを作ります。
  2. Geaspec アプリに、そのメールアドレスとパスワードでログインします。
  3. Discord のスレッドで「アプリを入れた」を押します。運営が確認して承認すると、貸し出せるようになります（承認されるまでは、借りる人には見えません）。

4. 貸せる時間を決める

  1. Geaspec アプリのホーム画面の下にあるカレンダーを見ます。1 マスが 1 時間です。
  2. 貸せる時間のマスをクリックします。なぞると、まとめて選べます。もう一度押すと外れます。
  3. 上の「◀ 前の週」「次の週 ▶」で週を切り替えられます。毎週同じなら「前の週と同じにする」が便利です。
  4. 選んだら「保存」を押します。保存すると、予約サイトの空き枠に出ます。料金の欄は 0 のままで大丈夫です（いまは無料の実験です）。
  5. 予約が入ったマスは色が変わり、アプリの上に「次の予約まであと何分」が出ます。予約が入ったマスは外せません。

5. 貸す日にすること

  • 貸す前に、貸し出し用の Windows ユーザーの VRChat からログアウトしておきます（アプリも開始前に消しますが、念のため）。
  • 貸す時間は、PC の電源を入れて、Geaspec アプリと Virtual Desktop Streamer を動かしたままにしておきます。
  • 開始の少し前に、アプリが前の人のデータを消して VRChat を準備します。貸し出し中は PC の画面が「利用中」の幕で隠れます。
  • 終わると、借りた人の VRChat のログイン情報や写真は自動で消えます（写真は消す前に予約サイトへ送り、借りた人が受け取れます）。

貸し出しが終わったら、データが消えたか確かめる（テスト項目）

  1. Geaspec アプリの「動きの記録」に「終了処理が完了しました。クリーンな状態です」と出ているか見ます。
  2. 貸し出し用の Windows ユーザーの「ピクチャ」→「VRChat」フォルダが空になっているか見ます。
  3. Steam から VRChat を起動して、借りた人のアカウントではなく、ログイン画面が出るか見ます（確かめたら閉じてください）。
  4. Discord のスレッドで「全部消えていた」か「残っていた」を押します。残っていたときは、運営がすぐ確認します。

読み終わったら、アプリに戻りましょう

Geaspec アプリに戻る

「Geaspec Agent を開きますか？」と聞かれたら「開く」を押してください。アプリを入れる前は、このボタンは使えません。
