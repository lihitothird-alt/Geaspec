はじめての方へ

テストに参加するときに使う画面を、画像で説明します。

1. Meta ユーザー名の見つけ方 2. 当日までの準備 3. 当日のつなぎ方 4. FPS と Ping の見方 5. PC を貸す人: アプリの入れ方

1. Meta ユーザー名の見つけ方

Discord で申し込むときに使います。表示名ではなく、ユーザー名のほうです。Virtual Desktop を持っている人は、VD で使っているものと同じです。

  1. スマホで Meta Horizon アプリを開きます。

  2. 下に並んでいるボタンの、まん中の人の形のボタン（プロフィール）を押します。

  3. 名前の下にある、@ で始まる文字がユーザー名です。申し込みには @ のあとの部分を入れてください。

2. 当日までの準備

  • 当日は PC 版の VRChat に、自分のアカウントで、メールアドレス（またはユーザー名）とパスワードを使ってログインします。Steam や Meta でのログインは使えません（Steam でログインすると、貸してくれる人のアカウントになってしまいます）。
  • Quest でいつも Meta のボタンだけでログインしている人は、VRChat の公式サイトにメールアドレスとパスワードでログインできるか、先に確かめてください。
  • 2段階認証をしている人は、確認コードを受け取るスマホも手元に置いてください。
  • 家の Wi-Fi で参加してください（スマホのテザリングだとつながらないことがあります）。
  • VPN は切ってください。Quest・スマホ・パソコン・家のルーターで VPN を使っていると、つながらないことがあります。
  • FPS と Ping の表示は、貸し出しの PC では毎回消えます。当日 VRChat に入ったら、下の手順でオンにしてください。
  • 自分の PC を貸す人だけ: 自分の PC に Virtual Desktop Streamer（無料・「Download Streamer」ボタン）を入れて、「Allow remote connections」（外からの接続を許可）にチェックを入れてください。借りるだけの人は何もしなくて大丈夫です（Quest の Virtual Desktop アプリだけで使えます）。

3. 当日のつなぎ方

  1. 開始 5分前に、Discord のスレッドで「テストを始める」を押します。
  2. Quest で Virtual Desktop を開き、パソコンの一覧から貸し出しの PC を選びます。
  3. VRChat が自動で立ち上がったら、メールアドレス（またはユーザー名）とパスワードで、自分のアカウントにログインします。Steam のボタンは押さないでください。
  4. 終わりの時間になると自動で終わり、ログイン情報はパソコンから消えます。

4. FPS と Ping の見方

  1. VRChat のメニュー（Launch Pad）の下にある歯車のボタン（設定）を押します。

  2. 設定をいちばん下までスクロールし、「デバッグ」の中の「FPS と Ping の表示」をオンにします。

  3. 画面に FPS と PING の数字が出ます。決められたワールドで 30秒ほど歩き回りながら、この数字を見てください（だいたいの数字で大丈夫です）。

FPS と PING が写るように Quest のスクリーンショット（右手の Meta ボタンを押したまま、トリガーを引く）を撮って、Discord の自分のスレッドに貼ってください。テストが終わってから、スマホから貼っても大丈夫です。

5. PC を貸す人: アプリの入れ方

借りるだけの人は読まなくて大丈夫です。

  1. Virtual Desktop Streamer（無料・「Download Streamer」ボタン）を入れて、「Allow remote connections」にチェックを入れます。

  2. Discord のスレッドに届いたリンクから、Geaspec アプリ（GeaspecAgent-Setup-….exe）をダウンロードして開きます。

  3. 青い画面「Windows によって PC が保護されました」が出たら、「詳細情報」を押します。まだ署名（お金がかかる証明書）をしていないために出る画面で、中身は公開しているプログラムです。

  4. 下に「実行」のボタンが出るので、押します。

  5. セットアップの画面で「インストール」を押します。

  6. アプリが開いたら、予約サイトのメールアドレスとパスワードでログインします。運営が確認すると、貸し出せるようになります。

準備ができたら、予約しましょう

予約する

開けないときは、Discord の自分のスレッドにある「サイトを開く」ボタンを押してください（あなた専用のリンクが届きます）。
