# 先輩に試してもらう手順（geaspec.com を通した通しのテスト）

PCVR（ゲーミング PC と VR ヘッドセット）を持っている先輩に、geaspec.com を通して
「貸す → 予約する → つなぐ → 終わる」が動くかを試してもらうための手順。

## いちばん確実な試し方
先輩の家の中だけで、先輩が「貸す人」と「借りる人」の両方をやる。
- 貸す人：先輩のゲーミング PC
- 借りる人：先輩の Quest（別のメールアドレスで作った 2 つ目のアカウント）

同じ家の Wi-Fi なら、ルーターの設定（Virtual Desktop が別の家からつながらない問題）に関係なく、
サイトとアプリの流れを最後まで確かめられる。別の家からつなぐのは、これが通ってからにする。

## Tailscale とポート開放
- 同じ家の中（PC と Quest が同じ Wi-Fi）なら、Tailscale もポート開放もいらない。
- 別の家からつなぐ場合、Tailscale を使わないなら、PC がある家のルーターでポート開放が必要（UPnP で自動で開くこともあるが確実ではない）。
  目安の番号は TCP 38810・38820・38830・38840（Virtual Desktop の公式ではなく、ポート開放の案内サイトに載っている番号。UDP が必要かは不明）。
- この「Tailscale なし・ポート開放あり」で別の家からつながるかは、まだ一度も確かめていない。
- v6プラスなどの回線ではポート開放ができないことが多い。その場合は Tailscale などの別の方法が必要。
- 0.7.56 で直したのは「Tailscale がないとアプリが貸し出しを始めない」ことだけ。つながり方そのものは変わっていない。

## 先輩に用意してもらうもの
- Windows のゲーミング PC（NVIDIA の GPU）
- Steam と VRChat（PC 版）。貸し出し専用の Steam アカウントがあれば、そちらを使う
- Virtual Desktop Streamer（PC に入れる。無料）
- Quest と、Quest に入れた Virtual Desktop（Meta のストアで買うアプリ）
- メールアドレス 2 つ（貸す用・借りる用）

## 手順

### A. 貸す人として（先輩の PC で）
1. geaspec.com を開き、右上の「アカウントを作る」で、貸す用のメールアドレスでアカウントを作る
2. いちばん下の「貸し出しアプリ（Windows）をダウンロード」を押して、アプリを入れる
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
3. アプリを開き、1. のメールアドレスとパスワードでログインする
4. 運営（杉井）に「登録した」と伝える → 運営が管理画面で「承認する」を押す
5. geaspec.com の「貸し出し」ページを開き、カレンダーでいまの時間（または次の時間）のマスを押して「保存」
   - 始まっている時間も、残りが 25 分以上あれば選べる
6. アプリで受付を始める（アプリは右下の小さなアイコンで動き続ける）
7. Virtual Desktop Streamer を開き、「Allow remote connections」にチェックを入れる

### B. 借りる人として（先輩の Quest、またはスマホ）
1. geaspec.com → Geaspec VR を開く
2. 「テストに参加している方は 空き枠を見て予約する」を押す
3. 借りる用のメールアドレスでアカウントを作る
4. 空き枠を選ぶ → 初回だけ Meta（Quest）のユーザー名を入れる → そのまま確認画面に戻るので「予約する」
5. 予約ページに「接続手順」が出る

### C. つなぐ前に（貸す人の PC で）
1. 「貸し出し」ページの「これからの予約」に、借りる人の Meta ユーザー名が出る
2. その名前を、Virtual Desktop Streamer の「Oculus/Meta username」に入れて保存する
   （アプリがまだ自動では入れられないため、ここだけ手作業）

### D. 遊ぶ
1. 予約の時間になると、アプリが VRChat を起動する
2. Quest の Virtual Desktop で先輩の PC を選んでつなぐ
3. VRChat に、借りる人の VRChat アカウントでログインして遊ぶ

### E. 終わる
1. 予約ページの「いま終わる（PC を返す）」を押す（または時間が来ると自動で終わる）
2. 30 秒ほどで、アプリが VRChat を閉じて、ログイン情報を消す
3. 予約ページが「終了」になり、貸し出しページに「終わった予約」が出る

## こちらで確かめたこと（2026-11-24）
作業場所で、本物のサイトと本物の貸し出しアプリ（実際には消さない試験モード）を動かし、
運営・先輩・借りる人の 3 人に分けて、上の A〜E を通しで行った。25 手順すべて通った。

途中で見つかって直したこと：
1. VR を「準備中」にしたため、VR の入口から予約に進む道がなかった
   → 空き枠があるときは「テストに参加している方は 空き枠を見て予約する」を出す
2. 貸す人が「いまの時間」を貸し出しにできなかった（次の時間まで最大 1 時間待つ）
   → 残りが 25 分以上あれば、始まっている時間も選べる
3. 借りる人が Meta ユーザー名を入れたあと、空き枠の一覧に戻され、もう一度枠を選ぶ必要があった
   → 選んだ枠の確認画面にそのまま戻る
4. 貸す人が、Virtual Desktop に入れる借りる人の Meta ユーザー名を知る方法がなかった
   → 「貸し出し」ページの「これからの予約」に出す

## こちらでは確かめられないこと（先輩の機械で見てほしいこと）
- Virtual Desktop で Quest から PC につながるか（とくに別の家から）
- VRChat が自動で起動するか、終わったときに閉じてログイン情報が消えるか
- SteamVR のメニューが開けないか、PC のスピーカーとマイクが消音になるか
- アプリの画面の見え方（Windows でしか出ない）
