# わかりやすさのチェックリスト

ほかの AI に厳しく見てもらった結果（重大 13 件）を、原因別にまとめたもの。
サービスの用途：Geaspec AI＝チャットで計算資源を使う／Geaspec Studio＝パソコンをまるごと貸し出し／Geaspec VR＝VRChat 限定の貸し出し。

## 1. 「登録」が3種類あって区別できない
- [x] ボタンを「押したら何が起きるか」の言葉にした
  - アカウント作成：「アカウントを作る」
  - VR の先行登録・AI/Studio の通知：「開始したらメールで知らせてもらう」

## 2. 色の意味がバラバラ
- [x] 主ボタンは全サービスで同じ濃い緑（白文字）にした。サービスの色はバッジ・見出し・吹き出しだけ
- [x] 淡いミントで「押せないボタン」に見えていた問題も、同じ直しで解消

## 3. 状態表示が実態とズレている
- [x] トップのカードを書き分けた：AI「試作中」／Studio「開始をお知らせ」／VR「先行登録受付中」
- [x] 英語版の VR「Available」を「Pre-registration」に
- [x] /slots の 0 件画面に「開始したらメールで知らせてもらう」ボタンを置いた

## 4. 押せないものがボタンに見える／押せるものが文字に見える
- [x] VR トップの「自分の VRChat アカウントで」などの白いピルを、枠のない文字＋アイコンに
- [x] フッターと案内の目次のリンクを「色＋下線」に統一
- [x] 今いるページの印を、灰色のピルから下線に

## 5. フォーム
- [x] 先行登録・お知らせのフォームに「必須」「任意」を表示
- [x] 同意の行は行全体を押せる（もともと行全体が label）。押せる手の形のカーソルに
- [x] 補足の文字を、読める濃さと大きさに
- [x] 「スマホ」を「スマホ（VRChat のスマホ版）」に、「VR なし」を「パソコンの画面で VRChat」に
- [x] 都道府県を地方ごとにまとめた

## 6. 細かいけど効くもの
- [x] 最上部バナーの「くわしく」を「実験について」に。スマホで途中改行しないように
- [x] AI ページのいちばん上に「AI に質問してみる（試作版）」ボタン
- [x] AI ページの例と使い方を、チャットの用途に合わせて書き直し、アイコンを内容に合わせた
- [ ] 言語の切り替えをヘッダーにも置く。「English」の行き先をサイトごとにそろえる
- [ ] スマホのメニューを、画面いっぱいのメニューにする（いまは右に浮くパネル）

## デザインの数値ルール（2026-11-24 に固定）
部品ごとに直すのではなく、先にこの数字を決めて、全ページをこれに寄せる。CSS は `server/app/static/style.css` のいちばん下の「デザインの数値ルール」が最終の決まり。

- 色（10）：主色 #15775a（ボタン・リンク兼用）／主色ホバー #0f6149／主色の上の文字 #fff／背景 #f3f5f5（全ページ1色）／面 #fff／薄い面 #eaeeee／線 #d9dfde／文字 #1d2424／補足の文字 #56615f／エラー #b42318
- サービスの色（AI #d0574f・Studio #7a5fd0・VR #3b8fd0）は、バッジの点だけに使う
- 文字：H1 48px／H2 32px／H3 20px／本文 16px／補足 14px（スマホは H1 32・H2 24・H3 18）
- 余白：8 の倍数。セクションの間 80（スマホ 56）、見出し→内容 24、カードの間 24、カードの内側 24
- 幅：容器 1120px、フォーム 560px、案内のページ 720px
- カード：白・枠線 1px・影なし の 1 種類だけ
- ボタン：主＝主色に白文字、副＝白に枠線。バッジ：ふつう（灰）と受付中（主色）の 2 種類

- [x] 上のルールを全ページに適用（トップ・AI・Studio・VR・案内・アカウント作成・空き枠・英語版で、背景・見出しの大きさ・主ボタン・リンクの色が一致することを確かめた）
