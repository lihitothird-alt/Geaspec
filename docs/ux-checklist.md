# わかりやすさのチェックリスト

ほかの AI に厳しく見てもらった結果（重大 13 件）を、原因別にまとめたもの。
サービスの用途：Geaspec AI＝チャットで計算資源を使う／Geaspec Studio＝パソコンをまるごと貸し出し／Geaspec VR＝VRChat 限定の貸し出し。

## 1. 「登録」が3種類あって区別できない
- [x] ボタンを「押したら何が起きるか」の言葉にした
  - アカウント作成：「アカウントを作る」
  - VR の先行登録・AI/Studio の通知：「開始したらメールで知らせてもらう」

## 2. 色の意味がバラバラ
- [ ] （配色は杉井さんの判断で、もとのサービスごとの色に戻した。主ボタンの色をそろえる案は保留）

## 3. 状態表示が実態とズレている
- [x] トップのカードを書き分けた：AI「試作中」／Studio「開始をお知らせ」／VR「先行登録受付中」
- [x] 英語版の VR「Available」を「Pre-registration」に
- [x] /slots の 0 件画面に「開始したらメールで知らせてもらう」ボタンを置いた

## 4. 押せないものがボタンに見える／押せるものが文字に見える
- [x] VR トップの「自分の VRChat アカウントで」などの白いピルを、枠のない文字＋アイコンに
- [x] フッターと案内の目次のリンクを「色＋下線」に統一
- [x] 今いるページの印を、灰色のピルから下線に

## 5. フォーム
- [x] 先行登録・お知らせのフォームに「必須」「任意」を表示
- [x] 同意の行は行全体を押せる（もともと行全体が label）。押せる手の形のカーソルに
- [x] 補足の文字を、読める濃さと大きさに
- [x] 「スマホ」を「スマホ（VRChat のスマホ版）」に、「VR なし」を「パソコンの画面で VRChat」に
- [x] 都道府県を地方ごとにまとめた

## 6. 細かいけど効くもの
- [x] 最上部バナーの「くわしく」を「実験について」に。スマホで途中改行しないように
- [x] AI ページのいちばん上に「AI に質問してみる（試作版）」ボタン
- [x] AI ページの例と使い方を、チャットの用途に合わせて書き直し、アイコンを内容に合わせた
- [ ] 言語の切り替えをヘッダーにも置く。「English」の行き先をサイトごとにそろえる
- [ ] スマホのメニューを、画面いっぱいのメニューにする（いまは右に浮くパネル）


## デザインの数値ルール（保留）
他の AI から提案された数値ルール（色10個・背景1色・主色 #15775a など）は、いったん当てたあと、杉井さんの判断で配色をもとに戻した。案として残す。
